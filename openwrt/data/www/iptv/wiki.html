日常管理

本说明对应源码中的新版六区控制台。既有 1.1.5 安装包和 Docker 独立管理页仍为旧界面；不要把源码改版当作已安装升级。

频道管理搜索、分组、逐条编辑、新增、保存和历史恢复。

播放与节目单

播放器通常订阅 new-logo.m3u，基础节目单为 new.m3u。从总览复制实际地址；EPG 使用本地 /epg.xml.gz 或兼容地址 /t.xml.gz。

频道管理中的修改先暂存，再统一确认保存。切换文件、刷新或恢复历史时会提示未保存内容；保存失败保留草稿。保存前重新读取源文件，如发现外部变化则停止覆盖。该检查不是服务器端原子锁，仍应避免与其他编辑器同时保存。

原始 M3U 和历史版本位于折叠区。普通逐条编辑保留其他频道、未知标签和排序；原始文本编辑则由操作者维护完整语法。运营商缓存 vsp.m3u 在此页只读，不作为正式节目单直接覆盖。

源发现

旁路由连接 IPTV 专网，NAS 负责媒体分析。日常被动采样不需要机顶盒开机，但十秒只会记录当时经过接口的流量，不能保证采齐全部频道。零观察不等于频道下线。

  • 立即采样：短时观察当前入口，不主动遍历地址。
  • 小范围扫描：仅在允许范围内有界检查，可能产生取流流量。
  • 验证待确认项：检查候选是否包含可识别音视频，不凭收到 UDP 包判断可播。
  • 复查无响应：每轮最多复查四个异常地址。夜间无节目不能直接判定失效。
  • 全量检查：覆盖正式节目单、历史地址和配置范围，不代表运营商全部地址池；支持暂停与续跑。

名称来源区分原节目单、流内信息、缓存候选和人工确认。名称待识别时可深度识别或核对后确认，不猜名称直接入库。实际内容未核实前不要勾选确认。

NAS 不可用时，已有结果标记为未更新，提交按钮停用；重连后恢复。导出提供差异 JSON 和候选 M3U，不自动代替正式节目单。

节目资料

EPG 来源每行一个 XMLTV 地址，可使用 XML 或 gzip 文件。台标模板每行一个，含 {name}；EPG 的 icon src 也可提供台标。没有图标的节目数据不能凭空生成真实台标。

一站式更新依次整理本地 EPG、提取并补全台标、生成必要的文字占位台标及带台标节目单。本地台标库为 /www/iptv/logos/。台标删除只针对对应图标文件，须先确认。

单项工具保留在折叠区。旧外部工具箱强制覆盖入口已移除；已有上游配置不会因此被自动删除。

自动任务

短采样、周全量和 EPG 更新分别配置。页面显示下次时间与最近执行结果；“已提交”不代表完整检查已完成。采用北京时间，工作日选项按周一至周五计算，不自动处理法定假期和调休。

短采样与周全量在同一分钟重合时，由全量替代短采样。全量只在观察心跳有效且未检测到播放时继续下一条取流，仍有每轮预算，不持续压满网络。

自动更新仅接纳已明确名称、单节目且重复验证通过的新源；同名换址还要求旧源最近七天内至少三次在北京时间09:00（含）至22:00（不含）无响应，间隔至少一小时、跨度至少24小时，最新检查仍无响应。新候选短样本有名称也会深度识别、间隔复核。最近成功的新增、换源、归档与恢复记录会保留显示。

“长期失效自动归档”默认关闭，单独确认后开启。至少3个不同日期在北京时间09:00（含）至22:00（不含）的完整检查无响应、跨度至少7天，且每轮有正常节目对照；大面积无响应、入口异常、未完成检查不会归档。每轮最多5条且不超过5%（小节目单最低1条）。归档移出正式列表但保留原名称、台标、排序和备份；恢复信号和身份、通过两次验证后自动恢复，不永久删除资料。每周检查一次时通常至少跨两周才能满足3次记录。

本地节目单已更新但 NAS 未确认时，显示“NAS 待同步”，后续仅补同步。未完成更新清单会阻止再次合并，需核对备份与当前文件，不通过清空状态掩盖问题。

系统维护

先查看诊断与日志，再按证据处理。机顶盒接口未连接是可选状态，不单独判定整个网关故障。

网络与接口

高级区保留接口选择、组播直连、地址更新、模式切换和 IPTV 身份参数。接口名因设备而异，必须核对接线；IPTV 接口不应成为家庭默认网关。修改可能中断播放，操作前保留原值与回退资料。

机顶盒与运营商工具

开机包、切台抓取及 VSP 获取仅供需要运营商会话的环境按需使用。可能包含 Cookie、会话标识等敏感数据，抓包与日志不得公开上传。HTTPS 或私有协议不保证能解析。

VSP 候选单独保存。合并前核对内容；候选表可能过期。无机顶盒的自动发现流程不依赖这些工具。

账号、外观与日志

右上角保留账号管理和深浅色切换。新安装需更改默认账号。当前采用配套玻璃主题；复杂主题编辑、背景上传、透明度调节和重复拓扑展示已移除，旧素材不自动删除。订阅地址配置收纳在系统维护底部。

日志来自旁路由服务端，便于跨设备核对。临时日志和抓包不能替代备份；不要在排障未完成时随意清理证据。

常见问题

  • 没有发现新源：确认入口、NAS 和采样记录。被动采样无流量时结果为空，不能推断所有地址不可用。
  • 扫描暂停：检查是否正在播放、观察心跳是否有效、NAS 是否在线或任务预算是否耗尽。
  • 播放失败：区分 IPTV 地址、组播路由、代理直连、udpxy 来源及单频道临时停播，不先删除频道。
  • 保存提示源已变化：保留本地修改内容，重新读取并核对，不强制覆盖自动发现的新结果。
  • 台标不显示：先检查实际台标 URL 是否可访问，再检查播放器指南或图像缓存。不要直接归因于缓存。
  • VSP 获取停滞：核对会话有效性和任务日志，不重复提交多个抓取任务。

本工具用于已开通的本地运营商 IPTV 服务，不提供公共直播源，也不默认开放公网管理。
