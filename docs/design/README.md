# IPTV 管理页设计与核验

## 功能重组基线

本轮改造采用六个入口：总览、频道管理、源发现、节目资料、自动任务、系统维护。后台播放和采样协议保持不变。

| 页面 | 保留的任务 | 调整 |
| --- | --- | --- |
| 总览 | 播放服务、订阅地址、最近任务、连接状态 | 去除重复状态画布和推测拓扑，不把机顶盒未接当故障 |
| 频道管理 | 查询、分组、逐条编辑、增加、保存与历史恢复 | 列表优先，原始 M3U 折叠；保留未知标签及排序 |
| 源发现 | 采样、验证、全量检查、差异、名称确认、历史、导出 | 设置移至自动任务；旧盲扫和一次失败删源入口移除 |
| 节目资料 | EPG、名称映射、台标库及补全 | 合并分散入口；外部旧工具箱强制覆盖入口移除 |
| 自动任务 | 工作日采样、周全量、自动更新、范围与 EPG 计划 | 集中展示下次时间和最近执行结果，保留失败保护 |
| 系统维护 | 诊断、日志、接口配置、机顶盒工具、账号 | 改网和抓包放进高级折叠区，保留确认和回退路径 |

移除的是过时前端入口，不删除后台兼容接口、生产配置、节目单或历史备份。保留既有认证机制，本次不扩大权限或改变网络。

### 视觉与交互规范

- 白色主画布、中性浅灰侧栏；深色为炭灰，不使用原有复杂皮肤、背景图或透明度设置。
- 192px 桌面侧栏，内容最大宽度 1536px；移动端顶部可滚动导航。区域无浮动卡片外框。
- 标题24px、分区标题17px、正文14px、标签12px，字距0。间距8/12/16/24/32px，圆角6px。
- 主要色 #087f77，信息蓝 #2563eb，警示琥珀 #b76b09，错误红 #c23838。深色单独配套。
- Lucide 20px、1.75px轮廓；工具图标配 title/aria-label，清楚命令用图标加文字。
- 表格、原始编辑器、对话框分别负责查看、批量编辑、单条编辑；未保存修改须保护，失败不得显示成功。
- 图片概念为总览和频道编辑状态的虚构示例，仅作为设计参考，不作为功能或现场验证证据。

## 设计原则

- 紧凑侧栏和无外框工作区，状态颜色区分正常、待确认和错误；不使用营销首屏。
- 浅色采用石墨文字、白色工作区、薄荷绿主要命令；深色使用中性炭灰底和清晰分隔。
- 初次跟随系统主题，手动切换只保存在当前浏览器。
- 保留必要业务、认证及网络行为；过时入口按上表移除，不因视觉调整修改设备配置。
- Lucide 轮廓图标，工具有提示，源码保留 ISC 许可证。
- 手机使用顶部横向导航、两列主要命令、换行表单；数据表仅在自身区域横向滚动。

## 自动发现

- 区分正式节目、观察地址、待确认差异和最近采样，不把收到包当作频道已验证。
- 支持名称来源、待确认过滤、单频道深度识别、已有频道表候选以及人工确认/撤回。
- 新增无响应复查与异常筛选；最新失败优先显示，曾识别媒体时保留历史提示。
- 新源显示有效复核进度，采样设置显示下一次短采样与全量检查时间。
- 名称确认必须核对内容；复查使用页内确认框。取消不提交任务。
- NAS 状态保存失败时，在操作区前显示存储警告；其优先级高于一般任务提示，避免显示旧的成功状态而掩盖错误。
- 显示两类计划的最近一次执行结果，区分已提交、已完成、失败和未确认；NAS 离线时保留上次显示的结果并标记未更新，禁用提交操作，恢复后重新开放。
- 自动更新区分本地已更新和 NAS 待同步，显示成功时间与条数；补同步确认后去除等待提示，保留成功记录，不把响应丢失显示为本地更新失败。

## 样例与验证

### 六区控制台（2026-10-26）

运行 `python3 discovery/console_fixture.py --port 50679`，打开 `http://127.0.0.1:50679/`。所有样例写入仅保存在内存，使用虚构频道和 TEST-NET 地址，不连接家庭设备。`--offline --fail-save` 用于验证离线与保存失败。

- 104 项 Python 测试与 8 项 Node 节目单测试通过，无跳过；覆盖原有后台、六页资产/ID、样例设置回读、保存/恢复、生产动作拒绝，以及逐条编辑保留未知标签、排序和其他行。
- 浏览器正常点击验证频道搜索、分组、分页、编辑暂存、确认保存及回读；未保存时切换文件取消后保留草稿；恢复历史只确认一次；运营商缓存禁止编辑。保存失败保留草稿和原文件。
- 源发现验证异常筛选、复查取消/确认、名称确认及人工来源显示；自动任务设置保存后回读；台标库搜索、维护日志及诊断入口通过样例核验。“全部记录”直接进入扫描记录页。
- 六区在 390px 和 320px 的文档宽与内容宽相同，无整页横向溢出。320px 下频道编辑框宽288px，内部可视/内容宽均286px；大表在自身范围横向滚动。已检查浅深色，当前浏览器未记录脚本错误。
- 使用 IAB 检查初始版面；原生确认窗口阻塞后，改用独立 Chrome 本机样例与页内确认继续交互验证。桌面截图原生宽1220px；移动尺寸由浏览器仿真，不等于实体手机验收。
- 尚未在本轮执行真实账号修改、台标上传删除、EPG 下载、网络配置或现场扫描。测试通过不等于新版已部署，既有 Docker 独立管理页和1.1.5包未改版。
